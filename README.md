# VISTA AI | Video Intelligence

A Python-based AI video assistant for turning meeting or lecture videos into structured insights. It downloads audio from YouTube or accepts a local file, chunks and transcribes it, summarizes the content, extracts action items and decisions, and lets you ask follow-up questions using a lightweight RAG layer.

## What it does

- Downloads audio from YouTube URLs or accepts local video/audio files
- Converts media into a processable WAV format
- Splits audio into chunks for transcription
- Transcribes using Groq-hosted Whisper for English or Sarvam AI for Hinglish
- Generates a meeting title and a concise summary
- Extracts:
  - action items
  - key decisions
  - open questions
- Supports transcript-based Q&A with a local RAG pipeline
- Exposes a Streamlit web UI for interactive use

## Prerequisites

Before running the project, make sure you have:

- Python 3.10+ installed
- FFmpeg installed and available on your PATH
- A Groq API key
- Optional: a Sarvam AI API key for Hinglish transcription

## Installation

1. Clone the repository
2. Create a virtual environment

```bash
python -m venv venv
```

3. Activate it

Windows:

```powershell
venv\Scripts\activate
```

macOS/Linux:

```bash
source venv/bin/activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

## Environment variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
SARVAM_API_KEY=your_sarvam_api_key
WHISPER_MODEL=whisper-large-v3
SARVAM_STT_MODEL=saaras:v4
```

## Running the app

### Streamlit web app

```bash
streamlit run app.py
```

This launches the UI for uploading or linking a video/audio source and running the analysis workflow.

### CLI mode

```bash
python main.py
```

You will be prompted to enter:

- a YouTube URL or local file path
- the language (`english` or `hinglish`)

## Example workflow

1. Paste a YouTube link or choose a local file
2. Audio is downloaded/converted into WAV format
3. Audio is split into chunks
4. Transcript is generated by Whisper or Sarvam
5. The app creates:
   - title
   - summary
   - action items
   - decisions
   - questions
6. You can ask follow-up questions about the transcript through the RAG assistant

## Notes

- The project is designed around meeting/video intelligence use cases.
- The transcription and summarization logic relies on external LLM/API services, so valid credentials are required.
- The RAG pipeline answers only from transcript context and will respond with a fallback message when the answer is not present.
